## 💼 주요 프로젝트

### 🧩 MeetU | AI 기반 커리어 매칭 플랫폼  
`2025.03.25 ~ 2025.04.28 (4주)` ｜ **팀장 & 백엔드 리드** ｜ [🔗 Backend](https://github.com/dpdlcl01/meet-u-career-backend) / [🔗 AI](https://github.com/dpdlcl01/meet-u-career-ai) / [🔗 Frontend](https://github.com/dpdlcl01/meet-u-career-frontend)

**기술 스택**  
`Spring Boot`, `JPA`, `QueryDSL`, `MySQL`, `Docker`, `GitHub Actions`, `FastAPI`, `React`, `AWS EC2`

**📌 프로젝트 개요**  
GPT 기반 자연어 처리와 벡터 유사도 분석을 통해  
이력서·자기소개서와 채용공고 간 의미 기반 정량 평가 기능을 제공하는 커리어 매칭 플랫폼

**🛠 주요 역할**
- 팀장: 일정 관리, Git 브랜치 전략 수립, 코드 병합 총괄
- CI/CD 파이프라인 구성: Docker + GitHub Actions → AWS EC2 자동 배포
- ERD 및 연관관계 설계: 총 35개 테이블 기반의 데이터 모델링 주도
- AI 자기소개서 코칭 시스템 구현:
  - FastAPI + OpenAI Embedding API + 코사인 유사도 → 직무 적합도 분석
- Presigned URL 기반 S3 보안 업로드 기능 구현
- QueryDSL + 조건 검색 + N+1 해결 + API 명세 관리 및 문서화

**🌱 느낀 점**  
도메인 모델링의 중요성, AI 기능을 통한 사용자 가치 창출,  
기술 도입부터 협업 설계까지 백엔드 개발자의 넓은 시야를 갖추게 된 경험

`2025.01.08 ~ 2025.02.07 (4주)` ｜ **팀장 & 백엔드 개발** ｜ [🔗 GitHub](https://github.com/dpdlcl01/CinemaProject)

**기술 스택**  
`JSP + Servlet (Model2)`, `MyBatis`, `Java 8`, `MySQL`, `Jsoup`, `Selenium`, `AJAX`, `JQuery`

**📌 프로젝트 개요**  
TMDB/KOFIC/KOBIS API 및 크롤링 데이터를 기반으로  
예매율 순위를 반영해 지역별 상영관에 자동 배치되는 영화 예매 시스템 구현

**🛠 주요 역할**
