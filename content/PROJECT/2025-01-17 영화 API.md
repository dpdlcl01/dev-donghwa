
- TMDB가 영화 포스터 URL을 제공한다는 것을 알고 있었기 때문에 이번 영화 API는 TMDB를 사용하기로 했다.
- TMDB에 회원가입해서 키를 얻어내었다.

#### 문제점
- 수업 시간에 배운 오픈 API의 응답 형식은 XML이었는데 TMDB는 JSON 형식으로만 응답을 지원한다고 한다.
- 수업 시간에 배운 것은 XML 형식으로 반환된 데이터를 JDOM 라이브러리를 사용하여 처리하는 방식이었다.

#### 해결책
- JSON 형식으로 반환된 데이터를 처리하려면 XML과 다른 JSON 파싱 라이브러리를 사용해야 한다.

### Java에서 자주 사용하는 JSON 파싱 라이브러리로는 **Jackson**이나 **Gson**이 있다.


##### 1. pom.xml에 jackson 라이브러리를 추가해야 한다.
- 임시로 영화 데이터만 받아오는 프로젝트를 만들었다.
- 추가한 라이브러리는 jackson (JSON 파싱 라이브러리), jstl(JSTL 형식을 사용하기 위한 라이브러리), javax.servlet-api (Servlet에서 api를 사용하기 위한 라이브러리)

##### 2. JSON 데이터는 문자열로 반환되므로 이를 Jackson의 `ObjectMapper`를 사용하여 파싱한다.

```java title:"MovieApiAction"
public class MovieApiAction implements Action {  
    @Override  
    public String execute(HttpServletRequest request, HttpServletResponse response) {  
  
        // 영화 데이터를 호출하는 경로 준비  
        StringBuffer sb = new StringBuffer("https://api.themoviedb.org/3/movie/popular?");  
        sb.append("api_key=8b259fc8ed83e644b26793b12795b088&");  
        sb.append("language=ko-KR&");  
        sb.append("page=1");  
  
        try{  
            // 브라우저 창에서 경로(url)를 입력하고 요청하듯이  
            // 프로그램 상에서는 요청할 때 URL 객체를 만들어야 한다.            
            URL url = new URL(sb.toString());  
  
            // 경로를 연결하는 객체  
            HttpURLConnection conn = (HttpURLConnection) url.openConnection();  
  
            conn.setRequestMethod("GET");  
  
            // 응답받을 데이터 형식 지정 (TMDB가 JSON만 지원)  
            conn.setRequestProperty("Content-Type", "application/json");  
  
            // 연결 - 요청  
            conn.connect();  
  
            // 응답 데이터를 읽어서 JSON으로 파싱  
            ObjectMapper mapper = new ObjectMapper();  
            JsonNode root = mapper.readTree(conn.getInputStream());  
  
            // JSON에서 필요한 데이터 추출  
            List<MovieVO> movieList = new ArrayList<>();  
            JsonNode results = root.get("results"); // results 배열을 가져온다.  
  
            if(results != null && results.isArray()) {  
                for(JsonNode item : results) {  
                    // JSON 필드를 추출  
                    String movieTitle = item.get("title").asText();  
                    String movieDate = item.get("release_date").asText();  
                    String moviePosterUrl = item.get("poster_path").asText();  
  
                    // VO 객체로 변환  
                    MovieVO mvo = new MovieVO();  
                    mvo.setMovieTitle(movieTitle);  
                    mvo.setMovieDate(movieDate);  
                    mvo.setMoviePosterUrl(moviePosterUrl);  
                    movieList.add(mvo);  
                }  
            }  
  
            // JSP로 데이터 전달  
            request.setAttribute("movieList", movieList);  
  
        } catch (Exception e) {  
            e.printStackTrace();  
        }  
  
        return "/movieList.jsp";  
    }  
}
```

#### 다시 발생한 문제점
- TMDB는 국가별 인기 영화나 트렌드 정보를 제공하지만 국내 박스오피스 데이터를 정확히 반영할 수는 없다.
- &region=KR 을 URL에 추가하면 대한만국에서 인기 있는 영화 데이터를 가져올 수는 있으나 "인기"는 TMDB의 자체 알고리즘(조회수, 평가 등)을 기반으로 계산된다.
- 영화 예매 프로젝트의 특성상 실제 사용자가 박스오피스 순위를 통해 영화 정보를 파악하고 예매할 수 있도록 하는 것이 중요하다.
- 따라서 단순히 국가별 인기 영화 정보만으로 데이터를 가져오는 것이 적합하지 않다.

- KOFIC에 회원가입하고 키를 얻어내어 데이터를 가져오기로 했다.

- 따라서 TMDB에서 이용한 Jackson 라이브러리를 활용하여 JSON 데이터 처리를 같은 방식으로 하기로 결정했다.

### **발표에서 관리자 화면을 활용한 시연에 대한 적절성**

**적절합니다.** 프로젝트의 발표에서 다음 요소를 포함한다면, 매우 흥미롭고 기술적으로 돋보이는 발표가 될 수 있습니다.

1. **관리자 화면과 버튼 구현**:
    
    - 관리자 페이지에서 실시간 데이터를 가져오는 버튼을 클릭하면, 크롤링 또는 API 요청이 수행되어 DB에 데이터를 저장하도록 구현합니다.
    - "실시간 데이터 수집"이 발표의 주요 기술적 포인트로 돋보일 수 있습니다.
2. **크롤링 및 API 사용**:
    
    - 크롤링 과정과 API 활용이 적절히 결합된다면, "기술적인 다양성과 실용성"을 보여줄 수 있습니다.
    - 크롤링은 실시간 데이터의 중요성을 강조할 수 있으며, API를 통해 안정적이고 효율적인 데이터 수집 방법을 보여줄 수 있습니다.
3. **DB에 저장 및 조회 과정 시연**:
    
    - 가져온 데이터를 DB에 저장한 후, 다시 화면에 표시하거나 대시보드로 시각화하면 데이터 파이프라인의 완성도를 보여줄 수 있습니다.
4. **사용 사례와 실용성 강조**:
    
    - "관리자가 실시간 데이터를 수집하여 DB를 업데이트하고, 이를 기반으로 사용자에게 최신 정보를 제공한다"는 시나리오를 제시하면, 발표 내용이 매우 실용적으로 보일 것입니다.

    - OS에 따라 ChromeDriver 버전이 Chrome 브라우저와 호환되는지 확인하세요.
2. **크롤링 대신 API를 보완적으로 활용**:
    
    - 크롤링은 네트워크 상황에 영향을 받을 수 있으므로, 문제가 생길 경우를 대비해 API 활용으로 대체할 방안을 마련하세요.
    - 크롤링과 API를 병행하면, **"크롤링은 최신 데이터, API는 안정성"**이라는 점을 강조할 수 있습니다.
3. **시연 준비**:
    
    - 버튼 클릭 시 데이터를 크롤링/가져오고, 이를 DB에 저장하는 시연 과정을 미리 테스트하세요.
    - DB에 저장된 데이터를 대시보드나 테이블로 보여주어 전체 과정이 한눈에 보이도록 하세요.
4. **비상 대책 준비**:
    
    - 발표 중 네트워크 오류나 크롤링 과정의 실패를 대비해, 미리 DB에 저장된 샘플 데이터를 준비해 두세요.
    - 버튼 클릭 시 샘플 데이터를 로드하는 방식으로 대체할 수 있도록 하세요.

##### KOFIC(한국영화진흥위원회) API에서 제공하는 박스오피스 API 응답의 주요 데이터
`dailyBoxOfficeList`에 포함된 데이터 필드

| JSON Key      | 설명                           | 예시                |
| ------------- | ---------------------------- | ----------------- |
| rank          | 해당 날짜의 순위                    | `"1"`             |
| rankInten     | 전날 대비 순위 변동 수치               | `"-1"` (1단계 하락)   |
| rankOldAndNew | 순위 신규 진입 여부 (`NEW` or `OLD`) | `"NEW"`           |
| movieCd       | 영화 코드 (KOFIC에서 부여한 고유 코드)    | `"20215042"`      |
| movieNm       | 영화 제목                        | `"스파이더맨: 노 웨이 홈"` |
| openDt        | 개봉일 (`YYYY-MM-DD` 형식)        | `"2021-12-15"`    |
| audiCnt       | 해당 날짜의 관객 수                  | `"54321"`         |
| audiAcc       | 누적 관객 수                      | `"12345678"`      |
- 데이터 타입은 모두 String
- 그 외에도 매출액, 관객 수 증감치, 상영 횟수, 상영 스크린 수 등이 있음

##### TMDB(더 무비 데이터베이스) API에서 제공하는 API 응답의 주요 데이터
`results` 배열의 주요 필드

| **필드명 (JSON Key)**    | **데이터 타입**       | **설명**                                          | **예시**                               |
| --------------------- | ---------------- | ----------------------------------------------- | ------------------------------------ |
| **id**                | Integer          | 영화의 고유 ID                                       | `634649`                             |
| **title**             | String           | 영화 제목                                           | `"Spider-Man: No Way Home"`          |
| **original_title**    | String           | 영화의 원제 (원어 제목)                                  | `"Spider-Man: No Way Home"`          |
| **overview**          | String           | 영화 줄거리 설명                                       | `"Peter Parker is unmasked..."`      |
| **release_date**      | String           | 개봉일 (`YYYY-MM-DD` 형식)                           | `"2021-12-15"`                       |
| **poster_path**       | String           | 포스터 이미지 경로                                      | `"/1g0dhYtq4irTY1GPXvft6k4YLjm.jpg"` |
| **backdrop_path**     | String           | 배경 이미지 경로                                       | `"/iQFcwSGbZXMkeyKrxbPnwnRo5fl.jpg"` |
| **genre_ids**         | Array of Integer | 영화 장르 ID 배열 (TMDB에서 정의된 장르 ID 목록 참조 필요)         | `[28, 12, 878]`                      |
| **popularity**        | Float            | 영화의 인기 점수 (TMDB에서 계산된 값으로 높은 값일수록 인기 있는 것으로 간주) | `1393.41`                            |
| **vote_average**      | Float            | 평균 평점                                           | `8.7`                                |
| **vote_count**        | Integer          | 평점을 매긴 사용자 수                                    | `14627`                              |
| **adult**             | Boolean          | 성인용 영화 여부 (`true` 또는 `false`)                   | `false`                              |
| **video**             | Boolean          | 비디오 여부 (`true` 또는 `false`)                      | `false`                              |
| **original_language** | String           | 영화의 원어                                          | `"en"`                               |

1. **id**: TMDB에서 영화 고유 식별자로 사용되는 ID. 다른 API 요청 시에도 활용 가능.
2. **title**: 영화 제목.
3. **original_title**: 영화의 원어 제목.
4. **overview**: 영화의 줄거리 및 설명.
5. **release_date**: 영화 개봉일.
6. **poster_path**: 포스터 이미지 경로. TMDB의 이미지 URL과 결합하여 사용해야 함 (예: `https://image.tmdb.org/t/p/w500` + `poster_path`).
7. **backdrop_path**: 배경 이미지 경로.
8. **genre_ids**: 영화 장르 ID 배열. TMDB의 장르 ID와 매칭하여 장르명을 확인 가능.
9. **popularity**: TMDB에서 계산한 영화 인기 점수.
10. **vote_average**: 영화에 대한 사용자 평균 평점.
11. **vote_count**: 평점을 남긴 사용자 수.
